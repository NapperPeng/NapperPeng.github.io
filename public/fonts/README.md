# Font attribution

This site uses Outfit, MiSans (小米 MiSans 字体), and JetBrains Mono.

- Outfit: Google Fonts official distribution, https://fonts.google.com/specimen/Outfit . Latin WOFF2: https://fonts.gstatic.com/s/outfit/v15/QGYvz_MVcBeNP4NJtEtq.woff2 . SIL Open Font License: `Outfit-OFL.txt`.
- JetBrains Mono: https://github.com/JetBrains/JetBrainsMono . Regular/Bold WOFF2 from the official `fonts/webfonts/` directory. SIL Open Font License: `JetBrainsMono-OFL.txt`.
- MiSans: Xiaomi original variable WOFF2 slices referenced by https://hr.xiaomi.com/website/assets/fonts/global.css , downloaded from `cdn-file.hyperos.mi.com/mi-font-service/misans_vf/VF/`. Files are unmodified; only the CSS family and resource paths are adapted for local hosting. Typeface copyright belongs to Xiaomi. Original font terms: `MiSans-License.pdf`, https://hyperos.mi.com/font/zh/ . MiSans is NOT Apache-2.0 or OFL. The font must not be sold or redistributed as a standalone font product, and must not be modified. These files are included solely as assets of this website; preserve this attribution and the original agreement when distributing the website. Do not extract/repackage them as a font distribution.

Retrieved 2026-10-27. Outfit Latin is preloaded; MiSans slices and JetBrains Mono are loaded only when needed. The 56 MiSans slices cover the upstream Unicode ranges, not merely today's article text, so future Chinese content does not require regenerating a subset. Other scripts fall back to the configured system fonts.
