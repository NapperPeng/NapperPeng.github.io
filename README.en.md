# NapperPeng Blog

A personal blog built with Astro. It uses an open layout focused on reading comfort, simple content organization, and carefully designed interactions.

Website: https://napperpeng.github.io/

## Features

- Blog posts, tag archives, and date-based archives
- Journal timeline
- Light and dark themes
- Custom cursor and article button interactions
- Responsive Markdown / MDX content management

## Tech stack

- Astro
- Tailwind CSS
- TypeScript
- MDX

## Content and configuration

- `site.config.ts`: site title, author information, navigation, and base settings
- `src/content/page/home.mdx`: Home page introduction
- `src/content/blog/`: blog posts
- `src/content/journal/`: journal entries
- `public/`: avatar, icons, and font assets

Current version: `v2.2`
