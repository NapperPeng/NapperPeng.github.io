# 鼠标与按钮交互实现验证

日期：2026-10-27。依据：v2-cursor-button-requirements.md（已审批）。

## 实现

- 新增 CustomCursor.astro、scripts/cursor.ts、styles/interactions.css；不新增项目依赖。
- 默认圆点与四角，吸附时从两端生成边线；主键按下增强框线、缩小圆点。
- 文章标题改为普通文本，覆盖式原生链接提供整块导航，Tag 独立置于上层，无嵌套链接。
- 稳定外层命中区域计算归一化坐标；内容二维偏移上限为水平 8px、垂直 6px。Tag 不重置文章位移。
- Astro 页面切换清理监听、观察器和动画循环；静止后停止动画调度。
- 导航移除旧背景缩放效果，保留透明和当前项颜色；图标统一轻量按压。现有项目没有普通实体操作按钮，因此仅提供相应填充样式，不凭空添加控件。

## 已验证

- 生产构建成功，15 个页面；构建前停止开发服务，之后以后台模式恢复。
- 中心偏移为 (0, 0)，左右测试分别为 (-7.2, 0)、(7.2, 0)，上下测试分别为 (0, -5.04)、(0, 5.04)；框与当前文章边界贴合，移开复位。
- Tag 框尺寸约 78.4 × 28px，匹配 Tag 可见区域；点击只进入标签页。
- 文章非标题区域点击及 Enter 导航正确；Tab 从文章主入口进入 Tag，整块键盘焦点可见。
- Ctrl 点击实际打开正确的新标签页；右键事件不被阻止。中键自动化测试等待弹出事件超时，未将其记为通过；实现未拦截中键或改写原生链接行为，建议人工补验。
- 文章四个边缘进入均能持续吸附；按下与释放状态正常。
- 博客、标签结果页、归档、标签索引、Journal、首页正常；连续三轮 Blog/Journal 客户端切换后仍只有一个鼠标组件且可吸附。
- 主题切换后导航 background 为透明、backdrop-filter 为 none。
- 减少动态效果时使用原生鼠标，文章无位移。
- 触屏文章与 Tag 分别跳转正确，移动菜单可打开，无自定义鼠标。
- 320、390、768px 无横向溢出。
- 禁用 JavaScript 后原生鼠标与文章链接仍可用。
- 实时偏移专项浏览器测试无 pageerror；git diff --check 通过。
