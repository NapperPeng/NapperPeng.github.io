# 自定义鼠标与按钮交互需求文档

- 文档日期：2026-10-27
- 状态：已审批，进入实现与验证
- 所属阶段：v2 视觉与交互改善，基于当前 v2.1
- 参考站点：https://lanrhyme.top/#/
- 本文中的“选中”默认指鼠标悬停，不指点击后的持续选中，也不指文本选择。

## 1. 目标与范围

建立统一的“圆点 + 四角框 → 吸附连线框”交互语言，使鼠标形态能够表达当前可操作范围。

本次包含：

1. 桌面端自定义鼠标及其移动、吸附、按下、离开状态。
2. 导航、Tag、分页、图标和普通操作按钮的反馈统一。
3. 博客列表文章整块点击，以及文章内 Tag 的独立点击。
4. 日间/夜间、触屏、键盘、减少动态效果及脚本异常的兼容。

不改变文章内容、路由地址、字体组合及当前开放式布局；不新增卡片背景、阴影或常驻文章边框。不引入参考站的乱码、故障抖动、全屏点击波纹或平滑滚动。

## 2. 已确认规则与建议默认值

用户已确认的核心规则：

- 普通鼠标为中心圆点与方框的四个角，角之间默认不连线。
- 吸附过程中生成角之间的连接线，最终形成完整边框。
- 文章标题取消独立链接，整个文章块成为文章入口。
- 文章内 Tag 是独立小入口，悬停时框住 Tag 的紧凑区域。
- Tag 优先于文章块；同一时刻只显示一个鼠标框。
- 文章悬停时，根据鼠标相对于文章中心的位置实时计算二维偏移量，不采用固定向右位移；离开后复位，鼠标框同步贴合偏移后的边界。
- 导航保持透明，当前页面的选中态只改变颜色，不添加下划线。

本文的具体像素、时长、按钮填充方式和作用范围属于建议默认值；随本文审批一并确认，实施时可在不改变上述规则的前提下做小幅视觉校准。

## 3. 鼠标视觉结构

鼠标视觉由三部分组成：

1. 中心圆点：准确跟随真实指针位置，不吸到目标中心。
2. 四角：四个等长 L 形角，默认围成一个不闭合的小方框，移动时轻微平滑跟随。
3. 连接线：默认隐藏，吸附时从角的端点向每条边中点生长，汇合后构成完整边框。

外框改变宽高时，角的长度与线宽保持稳定，不能整体拉伸导致角变形。框内部完全透明，不遮罩、不模糊、不调暗文章内容。

### 3.1 建议视觉参数

| 参数 | 初始值 |
| --- | --- |
| 圆点直径 | 4px |
| 默认外框尺寸 | 24 × 24px |
| 单个角边长 | 6px |
| 线宽 | 1px |
| 小目标框与点击边界间距 | 每侧约 4–6px，不能侵入相邻目标 |
| 文章内容到文章框内边距 | 约 8–12px，纳入文章自身布局 |
| 展开与连线总时长 | 约 240ms |
| 连线开始时机 | 展开开始后约 40ms，与展开重叠 |
| 离开收回时长 | 约 180ms |
| 文章悬停偏移 | 随鼠标相对中心的方向和距离动态变化；建议水平最大 ±8px、垂直最大 ±6px |
| 文章偏移平滑响应/复位 | 建议约 100–160ms 的跟随响应、约 200ms 复位；采用帧率无关的平滑插值 |
| 运动曲线 | 先快后缓，无明显弹跳 |

颜色沿用现有主题变量，不修改全站配色。普通状态略淡，吸附时增强对比度；优先直接适配明暗主题，不依赖混合模式才能看清。

## 4. 鼠标状态与切换

| 状态 | 外框行为 | 圆点行为 |
| --- | --- | --- |
| 普通移动 | 小四角框平滑跟随，连接线隐藏 | 准确跟随 |
| 进入可吸附目标 | 四角向目标边界展开，连接线生长 | 继续准确跟随 |
| 吸附完成 | 完整细线框包围目标 | 不移动到目标中心 |
| 按住主鼠标键 | 边框提高不透明度，不明显改变尺寸 | 建议缩小到约 80% |
| 松开 | 恢复悬停或普通状态 | 恢复原尺寸 |
| 离开目标 | 连线向四角收回，外框恢复小方框 | 继续跟随 |
| 离开窗口或窗口失焦 | 隐藏自定义鼠标，清除按压状态 | 同步隐藏 |

交互要求：

- 动画可中断、可反向；快速移动不排队播放。
- 从一个目标进入另一个目标，基于当前形态直接过渡，不先缩回默认框。
- 小目标可有 1–3px 的轻微磁吸偏移；文章根据鼠标相对中心的位置动态移动，大文章框同步贴合其当前可见边界，不叠加第二份独立偏移。
- 即使连线未完成，目标也立即可以点击，不等待动画。
- 滚动时按当前指针位置重新判断目标，不能仅等待下一次鼠标移动。
- 禁用控件不出现可操作的吸附/按压反馈。

## 5. 文章块与 Tag 的两级交互

### 5.1 文章主入口

- 标题为普通展示文本，不再拥有独立链接或独立鼠标目标。
- 文章块包括标题、摘要、日期、Tag 区域及块内留白；实际存在的字段按原内容展示。
- 悬停非 Tag 区域时，框包围整篇文章条目。
- 点击标题、摘要、日期或块内留白，进入对应文章详情。
- 两篇文章之间的间距不属于任何文章点击范围。
- 框内边距应由条目自身预留，框不能跨入相邻条目。
- 大块按下不做整体缩放、抬升或平移，只增强边框反馈。

#### 文章悬停偏移

- 进入文章块后，根据鼠标相对于文章未变换布局中心的位置，实时计算水平与垂直偏移。鼠标在中心时目标偏移为零，向左/右或上/下移动时，文章沿相应方向轻移；距离中心越远，偏移量越大，但有上限。不是进入后固定向右移动，也不是只触发一次的动画。
- 建议将相对坐标归一化：nx = clamp((pointerX − centerX) / (width / 2), −1, 1)，ny 同理；目标偏移 dx = nx × 8px，dy = ny × 6px。幅度为建议默认值，可在预览中校准。文章内容、主链接及 Tag 使用同一位移，离开整篇文章后平滑回到 (0, 0)。
- 每次指针移动更新目标偏移，以帧率无关的平滑插值跟随，避免生硬贴手或明显拖尾；按下时不增加第二份位移。
- 鼠标框在文章移动过程中同步跟随当前可见边界，不能只测量起点/终点，出现框与内容分离。
- 指针在文章与其 Tag 之间移动时，文章维持同一套实时偏移计算，不因目标切换归零或重新开始；只有框在大范围和 Tag 小范围之间切换。Tag 框跟随其可见位置，位移应轻微且平滑，不能导致 Tag 难以点击。
- 使用稳定的外层命中区和独立位移层；偏移计算始终以未变换的布局中心为基准，不能将已偏移的中心作为下一帧基准而形成反馈抖动。各边缘进入时不得因内容移动循环触发进入/离开；位移后的可见内容也必须可点击，不能出现视觉与命中错位。
- 使用 transform: translate(dx, dy) 实现，不增加旋转或 3D 倾斜；不改变相邻条目的排布、不挤压文章宽度、不改变文本换行。四周预留最大位移所需空间，避免遮挡相邻条目、裁切或横向溢出。
- 不新增背景、阴影、缩放或垂直抬升，保持开放式布局。
- 仅博客列表和标签结果页的文章块应用此效果；归档紧凑行默认不新增整体位移。
- 触屏与减少动态效果模式禁用该位移；键盘操作保留清晰的静态焦点轮廓，不依赖横向移动。

### 5.2 Tag 独立入口

- 每个 Tag 独立跳转至对应标签页，保持现有路由。
- 悬停 Tag 时，唯一的鼠标框从文章范围收缩至该 Tag；文章大框不保留。
- 点击 Tag 不触发文章跳转。
- 从 Tag 移回文章其他区域时，框重新展开至文章块。
- Tag 命中范围包含适量内边距；框与实际可点击区域保持对应，不能只把文字做成很窄的点击点。

### 5.3 命中优先级

明确的内层操作目标（如 Tag） > 文章块 > 默认鼠标。

| 指针位置 | 框选对象 | 点击结果 |
| --- | --- | --- |
| 文章非 Tag 区域 | 整篇文章块 | 打开文章 |
| Tag 区域 | 当前 Tag | 打开标签页 |
| 另一篇文章 | 新文章块 | 打开新文章 |
| 条目间距或列表外 | 默认小四角 | 无文章跳转 |

### 5.4 HTML 与原生链接行为

“按钮”是视觉描述；页面跳转仍使用原生链接语义，不用按钮模拟导航。

- 文章采用普通标题文本 + 独立覆盖式主链接 + 上层 Tag 链接的结构。
- 主链接通过标题文本取得可访问名称；不得出现链接嵌套链接。
- 保留右键菜单、Ctrl/Cmd 点击和中键新标签页打开行为。
- 每篇文章只有一个文章主链接焦点入口，另有各 Tag 的独立焦点入口。
- 鼠标装饰层不得接收点击或进入辅助技术阅读顺序。
- 覆盖链接方案会限制列表摘要拖选；建议本轮接受列表作为导航区域，文章详情中的正文、代码仍须自由选择与复制。若需列表摘要自由拖选，应先重新确认实现方案。

## 6. 各类按钮与链接的反馈

下表为建议默认方案，不新增不存在的功能控件。

| 类型 | 悬停反馈 | 按下反馈 |
| --- | --- | --- |
| 导航链接 | 紧凑吸附框、文字变色；无下划线或背景 | 轻微增强框线，不移动导航布局 |
| 文章块 | 根据鼠标相对中心位置实时二维轻移，吸附框同步贴合；无填充、阴影、额外抬升 | 增强框线，不新增缩放或位移 |
| Tag | 紧凑吸附、文字变色；不恢复胶囊卡片样式 | 轻微增强框线 |
| 普通操作按钮 | 吸附；适合有明确按钮边界者增加底色上滑填充 | 可缩至约 0.98，松开恢复 |
| 图标按钮 | 吸附、颜色增强，不做大幅旋转 | 可缩至约 0.96 |
| 分页、返回、归档等文字入口 | 紧凑吸附与变色，不统一强加填充背景 | 增强框线 |
| 正文内联链接 | 保留阅读型链接样式，不展开全行或整段大框 | 保留原生跳转 |

普通按钮填充动画建议约 200–300ms，使用伪元素位移实现；只用于明确的操作按钮，不应用到文章块、Tag 或导航。

当前页面导航、当前分页等持久状态与悬停分开管理：指针离开后保留原本的当前项标识，但不保留鼠标框。导航当前项仍只变色。

原有功能反馈（如复制成功）、主题切换逻辑和移动菜单功能保持，不因替换悬停/按压样式而消失。

## 7. 页面覆盖范围

- 博客列表和标签结果页：共用文章条目组件，应用相同整块点击规则。
- 归档页：保持紧凑条目布局，按独立文章行吸附，不扩展为摘要大块，不框住整年分组。
- 文章详情：正文不是整块按钮；Tag、返回和实际操作控件分别处理。
- 全站导航、分页及已有按钮：按第 6 节分类接入。
- 其他页面的普通文字、时间轴、分隔线、图片和装饰元素不因视觉上有边界而自动变成吸附目标。

## 8. 兼容性与可访问性

- 精细鼠标指针且支持悬停时启用；触屏操作不显示自定义鼠标，不以屏幕宽度作为唯一判断。
- 触屏保留文章整块点击和 Tag 独立点击，不要求先悬停；滚动手势不得误触跳转。
- 原生鼠标仅在组件初始化成功且当前设备适用时隐藏；脚本失败不影响链接和按钮使用。
- 输入框和可编辑区域保留原生文本光标；正文与代码保留文本选择能力。
- 键盘聚焦文章主链接时显示静态整块轮廓；聚焦 Tag/按钮时显示对应紧凑轮廓，不依赖鼠标位置。
- 焦点轮廓独立于唯一鼠标框，不隐藏键盘焦点。
- 对 prefers-reduced-motion 用户，建议禁用跟随形变动画并保留原生鼠标，控件使用静态颜色与焦点反馈。
- 日间和夜间均保证文字、圆点和框线清晰，主题切换不产生导航毛玻璃或遮罩。
- 鼠标进入/离开窗口、失焦、页面切换时清理残留状态，不出现卡住的大框或按下态。

## 9. 技术约束

- 使用 Astro 组件、原生 TypeScript 和 CSS，默认不新增运行时动画依赖。
- 通过显式 data 属性声明目标类型，避免全页面按 cursor:pointer 或标签名粗略自动吸附。
- 指针事件记录位置，requestAnimationFrame 统一更新视觉；平滑插值考虑帧间隔，避免刷新率改变手感。
- 位移与连线优先使用 transform/opacity；外框宽高变化仅影响隔离的鼠标装饰层，不改变页面布局。
- 缓存目标尺寸，在进入目标、滚动、窗口缩放、字体加载或目标尺寸改变时失效，避免每次移动遍历全页面。
- 文章位移期间须逐帧更新目标可见位置（或使用与文章相同的位移数据计算），不能只依赖 ResizeObserver，因为 transform 位移不会改变布局尺寸；过渡结束后恢复按需更新。
- 对接 Astro 页面切换生命周期：清除失效节点引用，避免重复事件监听、重复鼠标层或多个动画循环。
- 视觉层固定定位并设置 pointer-events:none；不能盖住真实操作，也不能进入浏览器顶部固定导航的不可见命中区域。
- 当前布局、字体、内容集合和路由逻辑不在本次重构范围。既有预览报错若复现应单独记录，不将其未经验证地归因于鼠标功能。

## 10. 验收标准

1. 默认只显示圆点与四角，角之间无连接线。
2. 悬停目标时四角展开，连接线从角端生长并闭合；离开时反向收回。
3. 快速切换多个目标无闪跳、排队、残留或重复框。
4. 文章标题不再是独立链接；非 Tag 区域均能进入对应文章。
5. Tag 优先收缩为小框，点击仅进入标签页；移动回文章恢复大框。
6. 条目间距不可点击，文章框不侵入相邻条目；鼠标在文章中心时目标偏移为零，向四周移动时文章按方向与距离实时轻移，幅度受限，框全程贴合，离开后复位。
7. Ctrl/Cmd 点击、中键、右键和键盘导航行为正确，无嵌套链接。
8. 博客列表与标签结果页行为一致，归档按行处理，文章正文不被误设为大按钮。
9. 导航持续透明，当前项仅变色，无下划线、背景遮罩或毛玻璃回归。
10. 明暗主题、窗口滚动/缩放、字体加载及连续页面切换后框的位置正确。
11. 触屏无自定义鼠标或悬停依赖；减少动态效果设置得到尊重。
12. 脚本禁用/初始化失败时原生鼠标可见，链接和按钮仍然可用。
13. 正文与代码可选中复制，输入区域保留原生文本光标，键盘焦点可见。
14. 页面无新增横向溢出、控制台错误或持续无意义的动画循环。
15. 从文章各边缘进入、穿过中心、在文章与 Tag 间往返、快速切换文章时，位移连续，无反复触发、抖动或点击错位；触屏及减少动态效果模式不执行文章位移。
